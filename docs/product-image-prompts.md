# Product imagery

Generated using the built-in imagegen tool. Final web assets are JPEGs in `public/images/products/`; untouched PNG originals are preserved locally in `artifacts/product-image-originals/`. JPEG encoding retains the original dimensions and composition.

These are generated, representative studio images, not manufacturer photographs of exact catalog SKUs. The same neutral tower image is reused across ready builds. For a live retailer catalog, replace the image mapping with verified product photography.

Direction: photorealistic commercial product photography, physically supported hardware, realistic materials and cable routing, neutral seamless studio backdrops, softbox key / soft fill / subtle rim, controlled glass reflections and restrained white lighting. Do not colorize images by retailer theme.

## Current mandatory no-text rule

Generated pixels must contain no readable branding, labels, model numbers, stickers, specification text, serial numbers, badges, component names, logos or pseudo-text. All visible surfaces must be blank and unbranded. Do not ask the image model to paint hardware names or specifications. Supply specifications to React as data and render them using semantic HTML/CSS callouts, leader lines and subtle markers. Preserve the photograph as a separate, reusable visual asset.

For future generation, append: `Every visible component surface is unbranded and free of any readable or pseudo-readable lettering, digits, etched text, printed labels, badges, serial numbers, stickers or logos. Do not render text anywhere in the photograph. The application supplies all labels separately.`
